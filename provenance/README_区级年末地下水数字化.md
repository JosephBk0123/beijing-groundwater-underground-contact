# 北京公报区级年末地下水埋深数字化 v1.0

核验日期：2026-09-21。来源为《北京市水资源公报》及年度锚点CSV。

## 1. 数据覆盖

- 主表：`beijing_district_groundwater_year_end_1980_2000_2025_digitized.csv`，298行。
- 2000至2025年：287行，包含260条单区记录与27条城区聚合记录。
- 1980年：另列11条参考记录；1981至1999年没有补值。
- 分区：通州、大兴、房山、门头沟、昌平、顺义、延庆、怀柔、密云、平谷，以及公报中的城区聚合单元。
- “城近郊”和“城六区”分别保留各自的 `spatial_unit_id`，未拆分为中心城区各区，因此本表不覆盖逐年16区。
- 2023年保留“城近郊”（2023公报）和“城六区”（2024公报重绘2023系列）两种标签；同年有12个记录单元，不代表12个独立行政区。没有证据证明两种聚合边界完全相同，因此不合并。
- 除2023年的双聚合标签外，2000至2025每年为10个外围区+1个城区聚合单元。
- “全市”柱作为图件控制项，单独进入审计表，没有混入区级主表。

## 2. 变量与统计口径

变量为地下水埋深 D，单位m，向下为正；不是地下水水位标高 head。
时间统计量为年末，当年12月31日用于标识统计期，不能据此判断所有井的实际观测日期。
空间统计为行政分区的平原区地下水埋深；并非整个行政区所有地表的等面积平均。
`district` 补上“区”后缀仅便于检索，`district_raw` 保留图中名称。未验证历年行政边界、井网和空间权重完全相同。

## 3. 数字化方法

优先利用PDF中的嵌入图像，避免整页截图二次压缩；2020年图使用PDF矢量矩形坐标。
2002、2012等含矢量绘图的页面采用可见图的渲染结果，未使用隐藏或重叠文本推断年份。
2003、2004、2006、2007为拍照/扫描版，依据坐标框做透视校正，再逐柱提取端点。
所有图逐年核对图例颜色和行政区排序，未假定跨年顺序一致。例如2025年延庆移到了顺义与昌平之间。
像素/矢量位置按图中轴刻度换算成m。全市正文数值只用于审计，没有用全市比例统一缩放区级柱高。
原始文件未修改；未运行地下水过程模型、DEM换算、空间插值、时间插值或暴露计算。

主表 `depth_m` 四舍五入至0.1m。`selected_unrounded_digitization_m` 和原始表中的三位小数用于复算，其小数位数不代表观测精度。
`digitization_error_scale_m` 是图件读取的操作性误差尺度，不是经统计校准的标准差、置信区间，也不包含井网代表性误差。
三维柱图存在端面、阴影与轴位置误差，扫描图还存在透视与印刷误差；这些值应视为图件数字化估计。

## 4. 主表来源选择

已提取的来源优先选当年公报的当年系列；缺少该来源时，选最近下一年公报中的上一年系列。
2000年取2001年公报，2005年取2006年公报，2011年取2012年公报。
2011年已由2012年比较图覆盖，未另行数字化gb2011.doc中的区图。
2005年源PDF未见区级比较图，因此采用2006年图中的2005系列。
2001年密云区本年图柱端被图例遮挡：原始读数留空，主表改用2002年图中的2001系列，并保留遮挡替代及初稿标记。
1980年主表参考统一选择2020年矢量区图，未对历年重复刊载的1980年柱取平均。其他版本保留在全来源表。
2024/2025图中的1980“城六区”参考保留在全来源表，没有合并进主表1980“城近郊”参考。
同年同名单位的多个图件读数全部保留；主表来源选择不等于裁定其他图件错误。

## 5. 审计结果与后续使用

提取23份公报的区级比较图，共828条来源记录：759条分区记录、69条全市控制记录。
其中1条原始柱端因遮挡未赋值；主表采用另一幅图的相同年/区来源，而非模型补齐。
主表共298行：210条为候选年末锚点，77条标记 `review_before_use`，11条为1980参考。
主表有22条记录触发相邻/重复公报差异筛查；其余需复核项还包含扫描图、初稿、图文控制差异和大年际变化。
这些标记用于提示复核，保留原值，不据此判断真实水文异常。

筛查规则（只标记）：
- 重复图件读数差 > max(0.5m，两次操作性读图误差尺度之和)；
- 同图全市柱与年度表差 > max(0.5m，该图读图误差尺度)；
- 同名同单元相邻年度变化绝对值 > 5m。
上述阈值用于数据质量筛查，不作为水文规律或插值模型的验收标准。

例如，2018年门头沟在2018公报区图中约17.0m，在2019公报重绘的2018系列中约41.0m。两种读数分别保留原值，未取平均、平移或按城市年末值修正。
2002公报封面标为“初稿”；2003公报重绘的2002系列与2002本年图在多个分区不一致，详见重复来源审计。
重复公报常重绘同一底层统计，它们不是独立观测；重复图一致仅说明刊载/提取一致，不能证明独立观测精度。

用于插值前，标记为 `candidate_anchor_not_interpolation_validated` 的候选输入需要先对齐区名、城区聚合范围和2019年后的逐期区表统计口径。
`review_before_use` 不宜直接作为插值的硬约束，须回源复核或做排除/区间敏感性处理。
1980参考不足以填补1981至1999年的区级空白；城区聚合记录也不足以推算各中心城区数值。
本表为年末图件数字化数据，尚未验证跨年空间统计范围的一致性，不是经验证的2000至2025区级月面板或固定空间支持的官方数值表。

## 7. 核心字段

- `year/date`：统计年份/年末时间标记；`is_1980_reference`区分基准年。
- `district_raw/spatial_unit_id/spatial_level`：原始分区、单元标识、单区或聚合区。
- `depth_m`：图件数字化的埋深估计；`record_type`明确来源是图而非原数值表。
- `source_file/source_pdf_page/source_figure/source_series_role/source_record_id`：可回溯到PDF和原始读数。
- `selection_rule`：主表为什么采用这幅图。
- `n_source_figures/source_reading_range_m`：同年同名单位的来源数与读数全距。
- `qc_flag/interpolation_anchor_status`：使用前复核要求。
- `cross_year_spatial_support_verified=False`：跨年空间统计范围的一致性尚未验证。

所有CSV采用UTF-8 with BOM，缺失为空字符串，不用0代替缺失。

脚本保留原运行环境的 `/mnt/data` 路径。迁移时修改脚本顶部的 D/O/W 路径，并将原始PDF和年度锚点CSV放入输入目录；运行不需要网络或OCR。
